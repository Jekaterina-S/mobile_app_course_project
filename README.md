Mobile Application course project

About

This application allows to view and favotire pictures of dogs from The Dog API (https://thedogapi.com/). An addition, it allows theme selection, font size changing and viewing amount of favorited images in settings section.
Favorited images can be seen in favorites tab.

This application was written in Kotlin and Android Studio.

Quick Start

Inside debug folder is a prebuilt apk file for viewing in an emulator or a real device.
